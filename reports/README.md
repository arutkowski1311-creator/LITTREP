# Clinical Intelligence Reports

Generated by the **Clinical Intelligence Engine**

## Open the dashboard

**[`index.html`](index.html) — LIT Library: Clinical Intelligence Hub** — the mission-control
dashboard. Open it locally (or serve this folder) to browse the whole corpus: metrics, brain
hero, What's New, indication focus, literature trending, top journals, trials at a glance,
saved searches, and per-section navigation (Literature, Guidelines, Trials, Technology,
Indications, Reimbursement, Expert Insights, Meetings, My Library). It reads `database.json`
directly — no network, nothing exposed publicly. ([`dashboard.html`](dashboard.html) remains as
a simple table-only view.)

## Run the scan on command

```
/clinical-scan baseline       # full library since 2020-01-01 (baselineStartDate in STATE.json)
/clinical-scan surveillance   # routine run — trailing 2 months (default)
```

`STATE.json` tracks the watermark (last run date) so surveillance runs cover the previous
two months without re-litigating earlier reports.
